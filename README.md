# Windows Update Toggle

A pair of Windows batch scripts that temporarily disable and re-enable Windows Update services.

These scripts are useful when you want to avoid Windows Update interruptions during:

- 🎓 Online exams
- 🎥 Presentations
- 🎮 Gaming
- 🧪 Benchmarking
- 💻 Long-running tasks

## Files

| File | Description |
|------|-------------|
| Disable_Windows_Update.bat | Stops Windows Update related services. |
| Enable_Windows_Update.bat | Starts Windows Update related services again. |

## Usage

1. Download the batch files.
2. Right-click the desired script.
3. Select **Run as administrator**.
4. Follow the on-screen messages.

## Requirements

- Windows 10 or Windows 11
- Administrator privileges

## Notes

- These scripts are intended for **temporary use**.
- Some Windows services (such as Windows Update Medic Service) are protected and may not stop on every system.
- Major Windows updates may restore default service settings.

## Disclaimer

Use these scripts at your own risk. They are intended to temporarily control Windows Update services and should not be used to permanently disable important security updates.
